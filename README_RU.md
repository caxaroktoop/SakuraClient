# Sakura Client v1.7

Companion-приложение для Minecraft Bedrock на Android: плавающая панель поверх игры, управление Spotify, свой прицел.

## Что нового в v1.7
- Окно модулей: категории, карточка у каждого модуля с переключателем и шестерёнкой настроек.
- Каждый виджет HUD — отдельный модуль со своим размером.
- Вкладки «Играть / Модули / Библиотека».
- Библиотека: миры (.mcworld), аддоны (.mcaddon/.mcpack), скины (.mcpack или PNG, который собирается в пакет). Кнопка «В игру» отправляет файл в Minecraft на импорт.

## v1.6
- HUD как в игровых клиентах: отдельные виджеты (время, таймер, заряд, пинг, CPS, ОЗУ, сеть) и редактор расположения: перетащи, куда удобно.
- Пинг до адреса твоего сервера (поле в приложении).
- Кнопка плей/пауза Spotify меняется сразу и надёжнее отправляет команду.

## v1.5
- Живое падение сакуры в приложении и (по желанию) поверх игры.
- Модули: свой прицел (4 стиля), HUD (время, таймер, заряд, пинг, ОЗУ, сеть), ночной режим.
- Новая стеклянная панель с вкладками «Плеер / Модули / Вид».

## v1.4
- Новый дизайн приложения и панели, иконка-сакура.
- Кнопка «Играть в Minecraft» включает панель и открывает Bedrock (исправлен поиск игры на Android 11+).
- Панель работает как foreground-сервис и не пропадает при сворачивании в игру.
- Панель перетаскивается, есть настройки прозрачности и размера, прицел (размер, цвет).
- Spotify: обложка, трек, прогресс, кнопки пред./пауза/след.

## Сборка
Push в GitHub → Actions собирает APK и публикует его в Releases.

## Ограничения
Zoom, Freelook, Replay и HUD Editor не реализованы. Приложение не внедряется в игру.
